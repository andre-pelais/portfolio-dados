# Portfólio para Análise e Ciência de dados

Este portfólio esta em processo de construção. Até o momento, dois projetos foram desenvolvidos. 

### spectrafit_toolkit

Este projeto automatiza o processo de análise de dados de espectros de fotoluminescência utilizando modelos estatísticos para o ajuste de curvas gaussianas e lorentzianas. Essa automatização permitiu diminuir o tempo de análise de dados experimentais de semanas para apenas um dia.

### Exploração de uma base de dados de ecommerce

A fim de realizar estudos de análise de dados utilizei esta base de dados de comportamento de compradores de um ecommerce para realizar uma análise de dados exploratória e retirar algum possível insight dos dados.
